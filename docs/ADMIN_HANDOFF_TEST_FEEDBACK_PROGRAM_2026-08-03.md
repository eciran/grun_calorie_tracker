# Admin Handoff - Test Operations Feedback

Open Test Operations > Feedback.

The workspace provides:
- paginated feedback inbox
- status, result, platform and route filters
- tester/build/device and safe last-request context
- short-lived private screenshot preview
- triage status and internal note
- top route and build coverage analytics
- HTTP failure and slow-request counters
- CSV export

Admin updates are audited. Never copy screenshot storage keys or credentials into the UI. A missing screenshot normally means none was attached, retention expired, or S3 is unavailable.

Before a preview release, verify the page with an ADMIN account and confirm a READ_ONLY account cannot change triage state.
